# Project origin and attribution

This repository is an independent portfolio refactoring of a project that
originated as an educational assignment about retrieval-augmented generation
and tool-using agents.

The original course notebooks and the course-provided `lib/` framework are not
included in this public repository. The application code in `src/` was
restructured as a standalone implementation with explicit orchestration,
configuration, tests, and documentation.

The small demonstration dataset contains widely known factual metadata about
video games. Its short descriptions were rewritten for this repository. Game,
platform, publisher, and franchise names remain trademarks of their respective
owners. The dataset is intended only as a technical demonstration and should
not be treated as an authoritative catalogue.
